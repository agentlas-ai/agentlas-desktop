Agentlas App Builder Pattern Notes

Lazyweb MCP health passed on 2026-06-03. This internal note extracts UI patterns only; deployed Agentlas copy must not name or imitate third-party services.

Patterns To Encode

Pattern A: App Inventory Grid

Use a searchable, scan-friendly grid/list for generated and installed apps. Each row should expose status, last update, primary action, and a compact description.

Pattern B: Prompt To Preview

Start with a clear goal input, then show the generated app blueprint, preview, editable settings, and export/open actions without leaving Agentlas.

Pattern C: Workflow Builder

For automation-heavy apps, represent the workflow as modular steps or blocks with state, approvals, and run history visible beside the editor.

Pattern D: Setup Checklist

When credentials, connectors, or approvals are required, present them as a short checklist and pause at secure boundaries instead of logging secrets into chat.
