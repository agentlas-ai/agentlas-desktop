# Academic Search

Agentlas Science의 선행연구 탐색을 여러 공개 학술 메타데이터 공급자와 프로젝트 출처 원장에 연결합니다.

| Workflow | Purpose |
|---|---|
| `search` | 질문에 맞는 공급자를 선택하고, 검색·중복제거·출처 보존·검증 한계를 적용합니다. |
| `full-text` | DOI/PMID가 확인된 출처의 Europe PMC 공개 원문 XML을 실제로 수집하고, 원본 hash와 결정적 파싱본을 함께 보존합니다. |

검색 결과는 논문 발견용 메타데이터입니다. 초록 또는 `full-text` workflow가 만든 parsed SourceVersion의 정확한 byte span을 확인하기 전에는 연구 결과가 실제로 특정 주장을 뒷받침한다고 판정하지 않습니다.
