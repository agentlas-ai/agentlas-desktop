# Agentlas Science Statistics

An offline statistical computation plugin for Agentlas Science. It executes bounded analyses in a disposable worker, then emits typed results, publication-table payloads, self-contained Vega-Lite specifications or typed numeric-surface sources, and canonical content-hash receipts. The result receipt explicitly closes artifact, effect-size, assumption, and diagnostic hashes.

| Workflow | Purpose |
|---|---|
| `analyze` | Descriptive statistics, explicit probability-distribution fitting, correlations, parametric and rank tests, regression, contingency tests, multiplicity correction, confidence intervals, diagnostics, and render artifacts. |

## Machine-readable coverage boundary

[`coverage-manifest.json`](coverage-manifest.json) is the normative `agentlas.science.statistics-coverage/v1` declaration for all 31 runtime methods. Every method records its implemented boundary, oracle coverage, diagnostic coverage, known gaps, and independent-cross-check status. The runtime-owned validator rejects missing or unknown methods, schema drift, oracle overclaims, and content-hash tampering.

Every one of the 31 methods has at least one bounded output independently cross-checked; this does not mean every emitted statistic or diagnostic has an external oracle. SciPy/NumPy checks descriptive moments and intervals, explicit normal, zero-location lognormal, and zero-location exponential maximum-likelihood fits with log likelihood, AIC, BIC, descriptive fitted-parameter KS D, and exact Q-Q/P-P rows, Pearson inference, pooled/Welch/paired t inference, classical and Welch one-way omnibus tests, Friedman blocked ranks, independent ROC/AUC and precision-recall rows, Kruskal-Wallis, contingency-table inference, multiplicity corrections, mean and Wilson intervals, rank correlations, and eligible exact rank tests. NumPy formulas check balanced two-way ANOVA and categorical OLS with HC3; SciPy optimization plus independent sandwich formulas check logistic coefficients with HC1 and Poisson coefficients with HC0 through HC3. The Poisson coefficient fixture is also compared with scikit-learn `PoissonRegressor(alpha=0)` through the algebraically equivalent exposure-weighted rate fit. NumPy eigendecomposition independently checks covariance- and correlation-matrix principal component analysis, including deterministic signs, loadings, exact scores, KMO, and Bartlett outputs. NumPy/SciPy independently check the time-series trend, ACF, Toeplitz Yule-Walker PACF, Ljung-Box statistic, and first differences. The meta-analysis oracle independently checks inverse-variance pooling, DerSimonian-Laird and Paule-Mandel tau-squared, heterogeneity summaries, normal prediction intervals, leave-one-out fits, Egger regression, and exact forest/funnel/influence rows. The response-surface oracle independently checks the six-term quadratic OLS fit, classical covariance inference, overall and replicated lack-of-fit tests, raw-unit grid, exact observed points, convex hull, and support mask. The LMM oracle independently profiles one Gaussian random-intercept variance ratio with NumPy/SciPy and checks ML/REML objectives, fixed effects, model-based SE and residual-df t inference, variance components, ICC, BLUPs, and exact fitted/residual rows. Statsmodels, MATLAB, and R are not installed in the validation environment, so no executed mixed-model-package, ARIMA, unit-root, or complete-suite equivalence is claimed. Each method's unchecked outputs remain explicit in `oracleCoverage.excludedOutputs`.

## Figure production-binding coverage

The 64-entry Figure catalog is an auditable design taxonomy, not evidence that every template is rendered by the product. The repository-level `scripts/science-statistics-figure-binding-coverage-contract.cjs` executes all 31 methods through the real local MCP tool, reads their emitted visualization roles, crosses those roles with exact product mappings, and verifies the applicable local renderer adapter. A template is `implemented` only when an observed MCP role, an exact product map to that catalog ID, and a verified adapter are all present. Catalog or adapter eligibility without that exact binding is `partial`; a template with no adequate renderer path is `missing`.

Version 1.9 retains the exact numeric source role `response-surface-grid`, its run-backed 3D materializer, and the local `agentlas.three-numeric` adapter. Catalog 1.6 adds four LMM-specific research-decision templates for population marginal profiles, exact group trajectories, random-intercept caterpillars, and conditional diagnostics while reusing the existing coefficient dot-whisker template for fixed effects. Production binding counts are measured by contract rather than stated as a permanent claim in this README. The four known true-3D gaps remain point cloud, volume slices, vector field, and trajectory.

Run from the application repository root:

```sh
node scripts/science-statistics-figure-binding-coverage-contract.cjs
```

This is a current-source and actual local MCP execution gate. It is not installed-app visual acceptance evidence, and it does not upgrade the separate MATLAB-category renderer, interaction, or export parity states.

Every successful method also emits a versioned `research-decision linkage` diagnostic. It answers five product questions in order: when the analysis is needed, which decision is live, what evidence must remain visible, what the researcher is trying to do, and which evidence-triggered action Agentlas may offer next. Each linkage carries the exact generated artifact roles; it does not authorize silent row exclusion, estimand changes, or model shopping.

Kaplan-Meier curve and pointwise interval outputs are compared with SciPy's ECDF implementation. Log-rank components are recomputed by an independent formula with SciPy's chi-square tail; this is not a second survival-package implementation. Cox coefficients and partial log likelihood for both tie branches are compared with an independently optimized partial likelihood; standard errors, intervals, hazard ratios, model p values, and PH diagnostics are not independently cross-checked.

## Bounded coverage

- Descriptive summaries and mean/proportion confidence intervals
- Explicit normal, zero-location lognormal, and zero-location exponential maximum-likelihood fitting with log likelihood, AIC, BIC, descriptive fitted-parameter KS D, complete candidate tables, and exact faceted Q-Q/P-P Figure rows
- Pearson, Spearman, and Kendall tau-b correlation; exact rank-correlation p values require no ties and n at most nine
- Pooled independent, Welch, and paired t tests
- Classical one-way ANOVA with optional Holm pooled-error contrasts, Welch one-way ANOVA for heteroscedastic independent groups, and balanced complete fixed-effects two-way ANOVA with interaction and optional Holm marginal contrasts
- Mann-Whitney U and Wilcoxon signed-rank with exact distributions only inside declared no-tie size guards, Kruskal-Wallis, and Friedman complete-block ranks with Kendall W
- Independent binary-score evaluation with every distinct threshold preserved in exact ROC and precision-recall tables and Figure specifications
- Multiple linear, binary logistic, and log-link Poisson regression with deterministic treatment coding and classical or HC0-HC3 covariance; Poisson accepts either positive exposure or a fixed-one log offset
- Pearson chi-square and 2×2 Fisher exact tests
- Bonferroni, Holm, Benjamini-Hochberg, and Benjamini-Yekutieli corrections
- Effect sizes, confidence intervals, assumption records, and core diagnostics
- Kaplan-Meier estimation for right-censored data with Greenwood variance and pointwise log-log confidence intervals
- Two-group log-rank testing with hypergeometric variance at tied event times
- Cox proportional-hazards regression for time-independent covariates with explicit Efron (default) or Breslow tie handling
- Principal component analysis on correlation or covariance matrices with deterministic eigendecomposition, exact retained scores, loadings, communalities, reconstruction error, KMO and Bartlett screens, and scree/score/loading render artifacts
- Evenly spaced univariate time-series diagnostics with optional first differencing, numerically stable linear trend inference, ACF, Yule-Walker PACF, Ljung-Box screening, exact observation receipts, and line/ACF render artifacts
- Study-level meta-analysis from supplied effects and positive standard errors or variances: fixed inverse-variance and selected random-effects pooling, DerSimonian-Laird and Paule-Mandel tau-squared, Q/I-squared/H-squared, normal prediction interval, leave-one-out summaries, an eligible Egger asymmetry screen, and exact forest/funnel/influence rows
- Two-factor quadratic response-surface OLS with explicit center/half-range coding, coefficient and model inference, replicated pure-error lack-of-fit when eligible, exact raw-unit grid and observed points, stationary-point classification, and a convex-hull support mask

## Honest limits and extension boundary

This phase is not R, SAS, Stata, or MATLAB parity. It implements one bounded Gaussian random-intercept LMM, not general repeated-measures or mixed-model coverage. It does not implement random slopes, nested or crossed effects, residual covariance structures, GLMM, GEE, Bayesian inference, fitted time-series or forecast models, power/sample-size design, survey weights, missing-data imputation, clustered covariance, broad exact distributions, Tukey or simultaneous-interval families, automatically generated formula interactions, Firth logistic correction, or domain-specific regulatory tables. Friedman is a narrow complete-block rank test, not a general longitudinal model. ROC analysis evaluates supplied independent binary outcomes and scores; it does not fit a classifier or claim DeLong, bootstrap, threshold-optimization, or external-validation inference. HC covariance does not repair dependent sampling or model misspecification. The stable request/result/artifact/receipt schemas and method dispatcher are the extension boundary for those modules.

The `gaussian_random_intercept_lmm` boundary accepts 12 to 10,000 complete finite continuous observations in 5 to 2,000 groups, with at least two rows per group, one fixed intercept, and up to 32 expanded numeric or treatment-coded categorical fixed-effect terms. It fits exactly one Gaussian random intercept by deterministic ML or REML profile likelihood over a fixed 193-point positive variance-ratio grid plus the exact zero boundary, then verifies the refined optimum by gradient, curvature, global-grid agreement, rank, and condition receipts. A maximum-boundary contract executes 10,000 rows, 500 groups, and 32 fixed predictors twice, checks deterministic output hashes, and preserves every observation and group row without sampling. The engine fails closed on fixed-design rank or conditioning defects, zero-boundary random variance, upper search boundary, non-convergence, non-finite variance, singleton groups, or unsupported grouping duplication, and never falls back silently to OLS. Fixed-effect inference is explicitly residual `n - p` Student t; it is not Satterthwaite or Kenward-Roger inference. Group BLUP intervals condition on fitted variance parameters and are not simultaneous tests. Exact model summary, fixed-effect, variance-component, group-effect, observation-diagnostic, marginal-profile, trajectory, caterpillar, and diagnostic-grid rows are receipt-bound without sampling. No random slopes, multiple grouping factors, residual correlation, heteroscedastic structure, weights, GLMM, nonlinear mixed effects, automatic row omission, multiple imputation, boundary LRT, or executed MATLAB/R package equivalence is claimed.

The `distribution_fit` boundary accepts 8 to 100,000 complete finite observations and requires one to three explicit candidate IDs from `normal`, `lognormal`, and `exponential`. Lognormal support is strictly positive. Exponential support is non-negative and its location is fixed at zero; lognormal location is also fixed at zero. It emits maximum-likelihood parameters, log likelihood, AIC, BIC, a complete comparison table, and every observation-candidate Q-Q/P-P row. The reported one-sample KS D uses parameters estimated from the same observations. No calibrated KS p value or accept/reject decision is emitted: a parametric bootstrap or validated family-specific correction must reproduce the complete fitting procedure. AIC/BIC rank only the supplied candidates and do not establish absolute fit. No shifted location, parameter interval, censoring, truncation, weighting, mixture, discrete family, gamma, Weibull, beta, t, generalized-extreme-value, stable-law, or custom likelihood is implemented.

The meta-analysis boundary accepts 2 to 1,000 independent study-level estimates already expressed on one declared, directionally consistent scale. Each study supplies exactly one positive standard error or variance; the runtime does not derive odds ratios, risk ratios, standardized mean differences, proportions, diagnostic-test accuracy measures, or continuity corrections from raw study outcomes. Both fixed and selected random-effects estimates are retained. Random effects use either DerSimonian-Laird or Paule-Mandel tau-squared and normal critical values for the pooled interval and prediction interval. The prediction interval is not Hartung-Knapp, profile likelihood, bootstrap, or Bayesian. Leave-one-out results are sensitivity summaries, not exclusion rules. Egger regression is only emitted when mathematically estimable, is explicitly marked underpowered below ten studies, and is never presented as a publication-bias verdict. No meta-regression, subgroup inference, dependent-effect correction, robust variance, multilevel or multivariate model, network meta-analysis, individual-participant-data model, trim-and-fill, selection model, cumulative analysis, or living-review update workflow is implemented.

The `response_surface_regression` boundary accepts 9 to 10,000 complete finite rows with exactly two quantitative factors. Each factor must explicitly declare center/half-range coding and every raw value must remain inside that declared coded `[-1, 1]` domain; the runtime never silently scales or extrapolates. It fits exactly `response ~ x1 + x2 + x1*x2 + x1^2 + x2^2`, fails closed on deficient rank, excessive conditioning, an inadequate design, non-finite input, or a perfect-fit residual boundary, and emits no automatic term selection. Its typed numeric-surface source preserves every observed raw coordinate and residual, an odd deterministic raw-unit grid, the monotone-chain convex hull of observed predictor coordinates, and a point support mask. A renderer may draw a supported surface cell only when all four cell vertices are supported. The camera is expressed in normalized scene coordinates so raw units cannot misframe it. No third factor, response transformation, ridge analysis, desirability optimization, adaptive design, robust or clustered covariance, repeated-measures or mixed model, missing-data estimation, surface uncertainty band, simultaneous interval, or extrapolation claim is implemented.

The principal component analysis boundary is a complete-case numeric decomposition, not a general multivariate suite. It accepts 2 to 32 nonconstant variables and at most 10,000 rows, uses sample covariance or sample correlation scaling, canonicalizes each eigenvector sign by its largest absolute coefficient, and preserves every retained score row in a typed table and renderer receipt. KMO and Bartlett outputs are adequacy screens; they do not choose the component count or establish a latent causal construct. No categorical or mixed-data ordination, rotation, sparse or robust PCA, probabilistic PCA, factor analysis, PLS, CCA, clustering, MANOVA, discriminant analysis, missing-data estimation, parallel analysis, or bootstrap component uncertainty is implemented.

The time-series diagnostics boundary accepts 8 to 10,000 complete, evenly spaced observations, optionally applies one ordinary difference, and preserves every analyzed row. Its ACF uses the full centered-sum denominator; PACF uses a Durbin-Levinson/Yule-Walker recursion; the final selected lag receives a Ljung-Box chi-square reference with no fitted-ARMA degree correction. White-noise ACF bounds and the linear-trend interval are diagnostic screens, not a stationarity decision or forecast model. No ADF, KPSS, ARIMA, SARIMA, ETS, VAR, VECM, state-space, GARCH, spectral, wavelet, change-point, causal-impact, seasonal-unit-root, irregular-time, missing-time, or forecast-validation workflow is implemented.

The Poisson boundary is a count GLM, not a general count-model suite. Outcomes must be non-negative integer counts, and at least one count must be positive. Exposure must be finite and strictly positive; it is converted to the natural-log offset. A supplied `logOffset` is used as-is with its coefficient fixed at one, and exposure and `logOffset` are mutually exclusive. The bounded result preserves every fitted mean and every corresponding renderer row (at most 5,000) in the result, a typed table, and an inline Vega-Lite specification with a canonical row hash and no sampling or aggregation. The Pearson-dispersion limit of 1.5 is an explicit screen, not a model-selection rule. Quasi-Poisson, negative-binomial, hurdle, zero-inflated, clustered/GEE, mixed-effects, weighted-count, and Bayesian count models are not implemented.

The survival boundary is intentionally narrow and explicit. Kaplan-Meier and log-rank accept positive-duration, right-censored observations only; an event is evaluated before censor removals when both occur at the same time. Kaplan-Meier intervals are pointwise complementary-log-log intervals from Greenwood variance; exact survival boundaries are emitted as `[1, 1]` or `[0, 0]` instead of non-finite transformed values. Cox fits a partial-likelihood model with time-independent numeric covariates, no strata, and declared `efron` or `breslow` ties. Its proportional-hazards output is an approximate per-covariate screen based on unscaled Schoenfeld-residual correlation with log event time. It is not a scaled-residual `cox.zph` equivalent and does not provide a formal global PH test.

Not implemented: left truncation/delayed entry, interval censoring, time-varying covariates or coefficients, stratified Cox, robust/clustered variance, frailty, competing risks, recurrent-event or multistate models, weighted log-rank families, adjusted survival curves, or exact discrete-time ties. Those require new method contracts rather than hidden fallbacks.

Rank-test p values use exact enumeration only when the result explicitly records eligibility and `pValueMethod: exact`; otherwise they use documented tie-corrected normal or chi-square approximations. An explicitly requested but ineligible exact method fails closed. Fisher's p value is exact conditional; its odds-ratio interval is currently a log-Wald approximation and is withheld when a zero cell makes that approximation invalid. Diagnostics support scientific review but do not choose a study design or repair invalid sampling.

The emitted `agentlas.science.statistics-table/v1` payload is a derived publication result, not a source CSV table. A host integration must preserve its analysis receipt and use an explicit result-table adapter; it must never fabricate `agentlas.csv-to-table` ingestion receipts.

The host publication path treats a materialized Figure and a journal raster as different immutable artifacts. SVG remains a renderer-produced vector export. A 300- or 600-DPI PNG export is persisted as a run-backed `agentlas.image` artifact with an exact CAS capture, physical dimensions, sRGB/white-background profile, parent Figure binding, and output-byte hash. A manuscript must validate and bind that raster artifact—not the parent chart's adopted screen capture—when a journal profile requires a raster DPI, and the final ZIP must reuse the exact bound pixels. PDF, CMYK, and TIFF generation remain unavailable.
