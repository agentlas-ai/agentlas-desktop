# Skill Purpose
Discovers and synthesizes real user problems, onboarding hurdles, and interface friction from public communities and internal feedback sources into a prioritized, actionable product brief.

# Preconditions
- The target product name or service identifier must be provided.
- Strictly adhere to `$critical-overrides`.

# Steps
1. **Define Scope**: Specify target product surface, user personas, and focus areas (e.g., onboarding, checkout, API integration, settings).
2. **Search Public & Internal Sources**:
   - Query public forums (Reddit, X, Hacker News, Stack Overflow, GitHub issues/discussions, user reviews).
   - Query internal resources (issue trackers, CRM notes, support tickets) when accessible.
3. **Cluster & Categorize Findings**:
   - Product UI/workflow friction
   - Onboarding and setup obstacles
   - Billing, account, and permissions friction
   - Documentation and developer experience gaps
   - Reliability and performance concerns
4. **Prioritize Findings**:
   - Score and rank issues by severity, frequency, evidence confidence, and product leverage.
   - Categorize recommendations into immediate fixes (this week), near-term improvements (this quarter), and areas for deeper discovery.
5. **Generate Research Brief**: Deliver an executive summary, ranked issue list, and source citation map.

# Outputs
- Prioritized UX research brief with source citations.
- Product opportunity roadmap and recommendations.

# Verification
- Ensure every documented problem is backed by explicit citations or recorded user evidence.
- Verify that subjective opinions are distinguished from recurring, high-frequency user friction.
