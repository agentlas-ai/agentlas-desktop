# Research Director Router

Use `$direct-study` when the request concerns the lifecycle or current state of one research study,
especially when work must cross several Agentlas Science Labs or end in a journal-ready manuscript.

Do not activate for a one-off literature lookup, a single chart edit, or direct manipulation of one
already-selected artifact unless the user asks to connect that operation back to the study plan.

This package coordinates host capabilities; it does not create them. If Agentlas Science does not
advertise a required capability, preserve the blocked phase and missing capability in state instead
of substituting an invented tool or result.
