# T-rex 덱 장르(대분류) 스펙

레이아웃을 4개 대분류로 구분한다. 각 장르는 **밀도 · 레이아웃 전략 · 에셋/이미지 비중**이 다르다.
장르는 `DeckContent.genre`(model.ts)로 주고, `buildDeckFromContent`가 로테이션/밀도를 장르에 맞춰 바꾼다.

## 1. 피치 (pitch) — 저밀도 · 차트+그림 중심 스토리라인
- 밀도 **낮음**. 한 슬라이드 한 아이디어. 텍스트 최소, 비주얼이 말한다(AI가 잘하는 영역).
- 로테이션: structure→diagram, process→flow, comparison→chart, metrics→chart/row. 즉 SVG 에셋 히어로 + 이미지(split/zigzag) 위주.
- 상태: **구현됨**(GENRE_ROTATION.pitch).

## 2. 리포트 (report) — 고밀도 · 고정 레이아웃
- 밀도 **높음**. 레이아웃 **무조건 고정**. 출처 표기 켤 수 있음.
- 구조: 제목(cover) → 목차(agenda) → 본문. 본문 2스타일:
  - **좌우형**(split/columns): 헤드라인(주장, **최대 2줄**) + 아래 좌우 분할이 이를 뒷받침.
  - **전체형**(full): 헤드라인(주장, 최대 2줄) + 아래 전체폭이 이를 뒷받침.
- 로테이션: structure→twopanel/columns/bento, metrics→row/bento, process→timeline/cards, comparison→bars/asym. **에셋 히어로(저밀도) 금지**.
- 상태: **구현됨**(GENRE_ROTATION.report).

## 3. 카드뉴스 (cardnews) — 인스타 캐러셀 · 이미지 중심 (리서치 완료, 빌더 미구현)
- 포맷: **4:5(1080×1350) 기본**, 1:1 옵션. 덱 전체 동일 비율 고정.
- **4:5 그리드 크롭 함정**: 프로필 그리드는 상/하 20%를 자른다 → 커버 훅/브랜드/얼굴은 **세로 중앙 60%(y 20~80%)** 안에.
- 시퀀스: **커버(훅)** → 콘텐츠 3~8장(한 장 한 아이디어, 열린 고리) → **CTA/요약**. 총 5~10장(7~8 스윗).
  - 커버: 5~8단어 초대형 제목, 리스티클 숫자("요즘 뜨는 5가지") 오버사이즈 글리프, 패턴 인터럽트.
- 카드 아키타입 6종(x,y,w,h %):
  - `fullbleed_scrim`(커버·강조): 이미지 0,0,100,100 + 하단 스크림 0,45,100,55(0→70%) + 헤드라인 6,60,88,28(하단정렬 흰색).
  - `top_image_bottom_text`(기본): 이미지 0,0,100,55(하단 라운드) + 텍스트 8,60,84,34.
  - `big_number`(리스티클/스탯): 숫자 6,8,50,40(액센트, 카드높이 30~40%) + 라벨 6,52,88,16 + 본문 6,70,88,22.
  - `quote`(감성): 큰 따옴표 6,10,20,20 + 인용 10,30,80,45(**명조**) + 출처 10,80,80,8.
  - `text_only_statement`(강한 주장): 풀 액센트/다크 배경 + 헤드라인 8,32,84,36(중앙 초대형).
  - `checklist`(팁): 제목 8,8,84,14 + 행 y28%부터 각 8,·,84,~13(간격 4%), 좌 10% 아이콘.
- 타이포: 카드당 1~2 사이즈. 커버 70~90pt, 콘텐츠 제목 35~45pt, 본문 15~20pt. 리딩=fontSize×1.618.
  - **고딕 기본**(정보/본문), **명조**는 감성/인용(quote)만. 최대 3폰트.
- 이미지: **대부분 카드에 이미지**. 텍스트가 이미지 위면 항상 스크림. 라운드 이미지 블록(radius 20~28px). 이미지-heavy/컬러블록 교대로 리듬.
- 스와이프: 카드 1~N-1 우측 "→" 또는 이미지 우측 블리드(~90,46,8,8). 진행 "1/7" 상단우측(~82,5,14,6) 고정 슬롯.
- 일관성(덱 상수): 단일 액센트(60-30-10), 카드당 2~3색, 브랜드 핸들 고정 푸터(6,94,50,4), 고정 슬롯.
- 밀도: 중간. 한 아이디어/카드, 본문 ~40 한글자 초과 시 새 카드로.

## 4. advertise — 포스터형 단일 오퍼 (리서치 완료, 빌더 미구현)
- 원칙: **Rule of One**(제품1·오퍼1·CTA1). F/Z 스캔 경로. 초점 1개. Squint 테스트 통과. **저밀도(여백 30~50%)**.
- 필수 4요소: **H(헤드라인) · O(오퍼/가격 뱃지) · C(CTA) · L(브랜드)**. O·C는 단 하나. 팝컬러는 O·C 전용.
- 선택: S(서브헤드), P(히어로 이미지 — 식음/리테일/부동산은 필수), 메타(날짜/주소/URL/@).
- 아키타입 5종(블록 %: H헤드라인 S서브 O오퍼 C CTA L로고 P이미지):
  - `image-dominant-overlay`(식음·부동산·여행): P 0,0,100,100(풀블리드+스크림) · L 6,6 · H 6,60,60,18 · S 6,79 · O 70,10,24,24 · C 6,88,34,8.
  - `split-block`(리테일·가구·테크): 좌 컬러블록/우 이미지 50 분할 · L 6,8 · H 6,30,40,22 · S 6,54 · O 6,64,26,14 · C 6,84,32,8 · P 50,0,50,100.
  - `centered-hero`(단일 SKU·화장품·음료): P 25,32,50,40(중앙 히어로) · H 12,14,76,14(위) · O 68,26,26,26(버스트) · S 20,74,60,6 · C 33,84,34,9 · L 40,6.
  - `diagonal-cut`(이벤트·세일·스포츠): 대각(0,65)→(100,35) 컬러블록/이미지 · H 8,10,62,20 · O 62,8,30,24(-8~-15° 기울임) · S 8,32 · C 8,44 · L 8,90.
  - `poster-frame`(교육·클래식·미니멀럭셔리): 6% 인셋 보더 · H 12,18,76,22(초대형 중앙) · S 15,42 · P 30,52,40,26(옵션) · 정보 15,80,70,8 · C 34,88 · L 40,10.
- 타이포: 사이즈 3~4개. 헤드라인 캡높이 ≈ 본문 3~5×(중앙/포스터형 5~8×). 오퍼 숫자가 헤드라인보다 더 클 수도. 웨이트 700~900. 리테일/식음 올캡, 럭셔리/부동산/교육 문장케이스. 한 단어만 강조.
- 오퍼 뱃지(폭 18~26%): 원형/스타버스트(할인·세일), 각진 태그(-8~-15°, 가격), 리본/코너배너(NEW·LIMITED·1+1), 숫자-히어로(퍼센트오프는 숫자 자체가 뱃지).
- CTA: 필(기본, 높이 7~9%, radius=절반), 라운드렉트, 화살표 접미. 동사 1개: SHOP/BUY/ORDER/BOOK/ENROLL/CALL NOW. 하단우측 또는 중앙하단.
- 색: 60-30-10. CTA·오퍼는 최대 대비 웜컬러. 컬러블록(사각/대각/원). 대각 8~20°(세일/이벤트만, 럭셔리/부동산은 직교).
- 업종 매핑: 식음(image-dominant/centered, 레드·옐로, ORDER NOW) · 리테일(split/diagonal, SHOP NOW) · 이벤트(diagonal/frame, 메타 필수, BOOK) · 교육(frame/split, 문장케이스, ENROLL) · 부동산(image-dominant/split, 뮤트·프리미엄, CALL/VISIT).

## 구현 순서
1. ✅ genre 축 + 피치/리포트 로테이션(model.ts GENRE_ROTATION).
2. ☐ 카드뉴스: 새 format 기본 4:5 + 카드 아키타입 6종 빌더(scrim/이미지블록/big_number/quote/checklist) + 스와이프/진행 슬롯.
3. ☐ advertise: 포스터 아키타입 5종 빌더 + 오퍼 뱃지/CTA 블록 + 필수4 검증.
