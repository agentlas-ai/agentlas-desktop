# Style DNA & Design Harness (Canon v1 — 2026-07-02)

시각물 생성 에이전트(슬라이드·웹·포스터)에 주입하는 디자인 규칙 하네스.
원리: **스타일은 명시적 규칙 집합이다** — "고흐 화풍"을 재현하듯, 거장/유파의 문법을
규칙으로 인코딩하면 모델이 재현한다. 감으로 정하는 수치 금지.

---

## 1. 타이포그래피 스케일 (수학적 비례 — typescale.com)

- **비율 1.2(minor third) 고정 사다리.** A4 기준 실측: h1 35.84pt · h2 29.86 · h3 24.89 · h4 20.74 · h5 17.28 · 주석 11pt.
- **역할 매핑(고정)**: h1=표지 제목+본문 페이지 헤드라인 / h2=서브 헤드라인(표지 부제) /
  h3=박스·컨텐츠 제목(카드 라벨) / h4=문단(리스트 행) 제목 / h5=박스 안 본문 / 주석=킥커·푸터·캡션.
  KPI 숫자는 텍스트 위계 밖(데이터 표시): h1×1.44.
- **페이지 크기 연동(연속식)**: 본문 앵커 h5 = `2.4 × √(높이/너비)` (캔버스 너비 % 단위, cqw).
  검산: 16:9→1.80 · A4 세로→2.85(스펙 pt와 일치) · 9:16→3.20 · 1:1→2.40. 3버킷 고정 금지 — 판형이 바뀌면 비율대로 따라간다.
- 위계 대비가 죽는 함정: 긴 제목 자동 축소 로직이 h1을 h2 아래로 떨어뜨리면 위계 역전 —
  축소는 26자부터 시작하고 h1 ≥ h2×1.05를 항상 보장.

## 2. 조판 4법칙 (줄바꿈)

1. **의미 단위 줄바꿈**: `word-break: keep-all; overflow-wrap: break-word;` 전 텍스트. 조사 쪼개기 금지.
2. **과부(orphan/widow) 방지**: 제목 `text-wrap: balance`(2줄 대칭/역삼각), 본문 `text-wrap: pretty`.
   미지원 환경은 `&nbsp;`로 마지막 두 단어 묶기.
3. **CPL**: 한글 30~45자/줄, 영문 45~75자. 넘치면 폭을 줄이고(하프앤하프) 옆에 이미지를.
4. **길이 제한**: 제목 1줄 최선·최대 2줄(≤24자 한글). 문단 최대 3~4줄, 넘으면 문단 분리+여백.

## 3. 60-30-10 컬러 + 동적 컬러

- 60% 바탕(부드러운 배경) / 30% 주제(잉크·서브 그래픽) / 10% 강조(단 하나의 주인공).
- **지표가 여럿이면 값은 잉크색** — 전부 액센트면 주인공이 사라진다. 액센트는 밑줄 바·앵커 번호·데이터 바·단독 히어로만.
- 동적 무드 인덱스(오프라인 폴백): VIBRANT SAAS(#0A2540/#635BFF/#00D4B2) · DARK LINEAR(#121318/#1C1D24/#5E6AD2) ·
  NEO-BRUTALIST(#FFF/#000/#FACC15) · MINIMAL EDITORIAL(#FAF6F0/#EAE3D9/#C2410C) · APPLE MINIMAL(#F5F5F7/#1D1D1F/#0071E3).
- 시드 컬러 → 조화 팔레트가 필요하면 `https://www.thecolorapi.com/scheme?hex=..&mode=monochrome|analogic|complementary&count=5`
  → colors[0]=60% 캔버스, colors[2]=30% 카드, colors[4]=10% CTA.

## 5. 이미지 3공식 (덩그라니 금지)

1. **풀블리드**: 화면 100% 사진 + 다크 스크림(40~60%) + 밝은 타이포. 표지·엔딩·감정 장표.
   *생성 이미지 도착 전에도 성립하도록 바탕을 다크 필드로.*
2. **하프앤하프**: 정확히 좌/우 50%(또는 40~48%)를 엣지-투-엣지 이미지로, 반대편은 단색+텍스트.
3. **소프트 엣지**: 누끼 또는 마스크 그라데이션 페이드(한쪽을 배경색으로 흐려 사각 프레임 탈출).
- **텍스트는 절대 이미지에 굽지 않는다** — 텍스트는 HTML 오버레이(safe-area 패딩 + overflow hidden).
- 이미지 스타일 혼합 금지(실사/3D/플랫 아이콘 한 화면 혼용 금지). 인물 시선은 텍스트/CTA 방향.
- **photoStyle**: 유파별 사진 룩 규정 문장을 생성 프롬프트에 접미(예: 스위스 = "single strong subject,
  off-white seamless, vermilion-red accents, hard geometric shadows, poster composition"). `no text/letters/numbers/watermark` 필수.
- **인포그래픽 도형 패널(graphicStyle)**: "디자인된 빈 패널"(모서리 장식만+중앙 완전 비움)을 생성해
  카드 배경으로 깔고 텍스트만 얹는다. 슬라이드당 1장 생성 → 그 슬라이드 카드 전부 공유(비용 1/N, 시각 통일).

## 6. 카드(박스)·리스트 공식

- **테두리 대신 면(fill) 또는 부드러운 그림자(shadow)**. 보더는 브루탈리즘처럼 보더가 조형 언어일 때만.
- 패딩 ≥ 글자 크기 1.5배(숨 쉴 공간). 모서리 radius는 산출물 전체 단일값.
- 리스트: 불릿(•) 대신 **숫자(01/02/03) 또는 아이콘 앵커** — 앵커에만 액센트 색(시선 리듬).
- 근접성: 그룹 내 간격 < 그룹 간 간격 (제목-본문 붙이고, 항목 사이 넓게).

## 7. 레이아웃 아키타입 15종 (역할과 분리, 로테이션 필수)

분할: ①2분할 50:50 ②3/4컬럼 ③비대칭 1:2(30/70 히어로+상세) ④모듈러 그리드
구조: ⑤벤토(히어로 셀+소셀 맞물림) ⑥매거진 멀티컬럼 ⑦계층형(70% 주인공)
흐름: ⑧Z-패턴(표지) ⑨F-패턴(본문) ⑩지그재그(이미지·텍스트 교차)
몰입: ⑪풀블리드 ⑫단일 초점(중앙 1요소+거대 여백)
특수: ⑬타임라인/프로세스(진행선+노드) ⑭허브앤스포크 ⑮탑다운 트리

- **같은 레이아웃 연속 금지** — 산출물 안에서 아키타입을 순환시킨다(자동 로테이션 또는 명시 지정).
- 검증된 물리 제약(슬라이드): 벤토 셀 최소높이 ≈ 17%(패딩+수치+라벨) — 안 들어가면 셀 수를 줄이거나 라벨만.
  타임라인 상하 교차 배치는 텍스트 높이 예측 불가 → 단방향(텍스트 위+라인 아래)이 안전.

## 8. 차트/데이터 시각화 규칙

- 격자선 삭제 또는 초연한 회색(#F3F4F6, opacity 0.05 수준). 데이터가 주인공.
- 기본 범례 끄고(HTML로 직접 조판, h4 위계) / 에어리어 차트는 30%→0% 세로 그라데이션 / 바 모서리 radius는 카드와 통일.
- 단순 비교는 라이브러리 불필요: div height/width % = CSS 하이브리드. 화려한 축·가이드는
  배경 이미지로 생성하고 수치 텍스트만 absolute 오버레이(하이브리드 공식).
- 라이브러리 권장: Chart.js(캔버스 속전) / Recharts(React) / ApexCharts(폴리시·그라데이션).

## 9. 마이크로 인터랙션 & 등장 애니메이션 (웹/HTML 산출물)

- 버튼: `transition: all .25s cubic-bezier(0.16,1,0.3,1)` + hover translateY(-2px)+섀도 확장, active scale(0.97).
- 로딩: 스피너 대신 **셔머 스켈레톤**(움직이는 회색 그라데이션).
- 등장: 리스트는 스태거(100ms 간격), opacity 0→1 + slideY 20px→0. 히어로 제목은 overflow hidden 마스크 슬라이드 업.
- 스크롤: sticky 피닝 + 패럴랙스. React면 Framer Motion(staggerChildren), 원시 JS면 GSAP scrollTrigger.

## 10. 기타 하드 룰

- 8pt 그리드(여백·간격 8의 배수; 슬라이드 등가 = 세로 4% 리듬), 좌측 정렬선 단일화(칼같이).
- "감사합니다" 류 정보량 0 페이지 금지 — 마지막은 핵심 메시지로 닫는다.
- 페이지의 최소 80%는 텍스트·도표·그림이 일해야 한다(장식 아닌 정보). 하단 여백은 인사이트(So-what) 바로 채운다.
- 시선의 주인공 체크: "0.5초 만에 봐야 할 단 하나(10% 강조)"가 명확한가.
