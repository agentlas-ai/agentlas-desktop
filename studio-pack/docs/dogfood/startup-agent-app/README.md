# Dogfood Run: Startup Package Agent App

Status: active dogfood run
Date: 2026-06-19
Founder posture: sell a Startup package agent app to people who want to start a
company but do not know how to move from idea to evidence, PRD, build, and launch.

## Product

**Startup Studio** is a paid agent app that turns a founder's raw idea into:

1. a pressure-tested business idea;
2. market and competitor evidence;
3. a simple business plan;
4. PRD, workflow, screen spec, and wireframes;
5. a Google Stitch design handoff;
6. app and web build lanes;
7. QA and launch evidence.

## Dogfood Contract

This run uses the repository's own Startup package as the product workflow. The
goal is not to write a fantasy plan. The goal is to identify what breaks when a
real founder tries to use the package, then fix the package.

## Current Verdict

`BUILD`

The product is sellable if the user sees a real lifecycle, not a chat prompt.
The biggest risk is credibility: founders must trust that the app produces
useful artifacts and not generic AI output. Google Stitch should be used as the
visible design bridge, but only after account/API-key readiness is explicit.
