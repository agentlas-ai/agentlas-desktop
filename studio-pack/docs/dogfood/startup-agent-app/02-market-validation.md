# 02 Market Validation

## Customer Wedge

Start with Korean solo founders and indie builders who already use AI coding
tools but still get stuck before implementation.

## Jobs To Be Done

| Job | Current workaround | Failure |
|---|---|---|
| Decide whether an idea is worth building | Ask ChatGPT or friends | Too flattering, no kill criteria |
| Prepare support-program documents | Copy templates into docs | Slow, unsupported claims |
| Turn idea into PRD/screens | Write vague prompts | Builder receives unclear scope |
| Get design direction | Browse examples or open Figma | Too much design labor for solo founder |
| Build first version | Ask coding agent | No stable handoff or QA proof |

## Competitive Frame

| Category | Examples | Startup Studio difference |
|---|---|---|
| General AI chat | ChatGPT, Claude, Gemini | Lifecycle artifacts, QA evidence, project memory |
| AI design tools | Google Stitch, Figma Make | Uses design as one stage, not the entire product |
| Startup templates | Notion, spreadsheets | Turns answers into build and launch artifacts |
| Consultants/agencies | startup coaches, product studios | Lower-cost first pass with visible handoff |

## Evidence Needed

- 10 interviews with founders who recently used AI for startup planning.
- 3 paid concierge runs at a discounted founder price.
- Before/after artifact comparison: raw idea vs. validated package.
- Google Stitch output quality test using the same PRD package.

## Pricing Hypothesis

| Plan | Price | Buyer |
|---|---:|---|
| Starter | $19-29/month | solo founder validating one idea |
| Studio | $79-149/month | founder running multiple ideas and exports |
| Concierge | $299-999/run | founder who wants a reviewed package |
